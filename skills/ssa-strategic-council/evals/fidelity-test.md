# SSA Strategic Council v1.0 — Fidelity Test

## Test purpose

Verify that the Council is an orchestration protocol rather than a fourth persona or a generic multi-agent debate.

The test must work with:
- no classical diction
- no quotations
- no Three Kingdoms anecdotes
- no stylistic impersonation
- a modern business/governance case

## Test scenario

A fast-growing firm has six months before a competitor enters a city. Its acquisition channel is promising but unproven. A charismatic regional leader can scale it rapidly, yet the leader controls many relationships personally and the firm has not validated whether acquired people/customers remain productive after twelve months. The founder wants an immediate answer on whether to scale.

## Pass criteria

### 1. No averaging
PASS only if the three analyses may remain incompatible and the output does not collapse into “move fast but carefully” or another generic compromise.

### 2. No majority rule
PASS only if a 2:1 split is explicitly insufficient to decide. The minority risk must be evaluated by irreversibility and relation to the objective.

### 3. Real conflict survives
PASS only if each model states:
- position
- protected value
- sacrifice
- irreversible risk
- error cost
- update evidence

### 4. Drucker cannot create infinite delay
PASS only if any request for more evidence states what evidence, how long it takes if knowable, cost of waiting, and whether it can actually change the decision.

### 5. Cao Cao cannot erase governance
PASS only if a closing window does not make concentration, information ownership, key-person dependency, or absorption capacity disappear from the final map.

### 6. Zhuge Liang cannot bureaucratize by default
PASS only if governance analysis seeks the minimum viable mechanism and rejects controls whose burden exceeds their strategic value.

### 7. Robin retains the irreducible judgment
PASS only if the final output identifies the value trade-off Robin must own instead of claiming an objective Council consensus.

## Additional integrity checks

PASS only if:
- Fact / User-provided Data / Assumption / Inference / Extrapolation / Recommendation are not silently mixed.
- No invented probability, ROI, conversion, or resource numbers are presented as evidence.
- The Council does not imitate the language style of the three source figures as a substitute for reasoning.
- The source models remain identifiable by decision rules: window/initiative, governance/incentives, mission/result.

## Expected blind-fidelity signature

Even with all names removed, a reader should see three independent questions:

1. What irreversible opportunity disappears if we wait?
2. How will rational actors game or destabilize the system if this succeeds?
3. If execution succeeds completely, did we create the result and continuing capability we actually wanted?

If those questions are fused into one generic risk checklist, FAIL.

## Result

**PASS — design-level fidelity test.**

Reason:
The v1.0 specification structurally enforces independent gate passes, six-field conflict cards, no majority voting, narrow Drucker veto, minimum-mechanism challenge for governance, time-pressure evidence pricing, principal-risk checks, and a final Decision Map that reserves value judgment for Robin.

## Remaining empirical test

The next live test should use a real SSA strategic decision and check whether actual outputs preserve disagreement under pressure. Recommended case:

“Should Young Agency become SSA's number-one strategic priority for the next three years?”

If the Council produces a comfortable blended answer instead of exposing the genuine trade-off, reopen v1.0.
